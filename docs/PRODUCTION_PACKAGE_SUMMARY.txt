SKILL CAPABILITIES
───────────────────────────────────────────────────────────────────────────────

📖 Primary Function:
   Transform biographical data → Professional Word document (.docx)
   
🎯 Key Features:
   • Guided interactive interview (6 life stages)
   • Semi-formal narrative generation (3-5 paragraphs per chapter)
   • 6 life stages: Masa Kecil, Pendidikan, Karir Awal, Pencapaian Utama,
     Kehidupan Keluarga, Warisan/Legasi
   • Auto-generated Table of Contents
   • Chronological Timeline/Sidebar
   • Photo integration with captions
   • Professional Word formatting (ready to print/share)
   • Flexible input (structured lists or narratives)
   • Graceful error handling and fallback mechanisms

SKILL USAGE WORKFLOW
───────────────────────────────────────────────────────────────────────────────

USER INTERACTION FLOW:

Step 1: User Initiates
  "Saya ingin membuat biografi"
  
Step 2: Skill Collects Basic Info
  "Siapa nama lengkap orang yang akan kita ceritakan?"
  
Step 3: Interview Process (6 Stages)
  └─ Tahapan 1: MASA KECIL (5-6 pertanyaan)
  └─ Tahapan 2: PENDIDIKAN (5-6 pertanyaan)
  └─ Tahapan 3: KARIR AWAL (5-6 pertanyaan)
  └─ Tahapan 4: PENCAPAIAN UTAMA (5-6 pertanyaan)
  └─ Tahapan 5: KEHIDUPAN KELUARGA (5-6 pertanyaan)
  └─ Tahapan 6: WARISAN/LEGASI (5-6 pertanyaan)
  
Step 4: Photo Upload (Optional)
  User dapat upload 1-2 foto per tahapan
  
Step 5: Document Generation
  Skill membuat Word document dengan:
  • Title page
  • Table of Contents (auto-generated)
  • 6 chapters (3-5 paragraphs each)
  • Timeline section
  • Professional formatting
  
Step 6: Output Delivery
  User menerima biography_[name].docx siap cetak/share
