## Installation Instructions

### Method 1: Direct Script Download
```bash
# Download files
git clone https://github.com/[org]/biography-writer-skill.git
cd biography-writer-skill

# Install dependencies
pip install -r requirements.txt

# Run tests
python run_all_tests.py

# Usage
python -m biography_writer
```

### Method 2: Package Installation
```bash
# Install via pip
pip install biography-writer

# Import in Python
from biography_writer import BiographyGenerator

# Use the skill
bg = BiographyGenerator("Your Name")
```

### Method 3: Claude Direct Integration
```
User simply says to Claude:
"I want to use the Biography Writer skill"

Claude enables the skill automatically
User begins interactive interview
```
